# El Cazador del Wins — Automação de Vídeos Curtos (Etapa 1)

Repositório da arquitetura de gravação de tela, telemetria e automação de interface para produção em escala de Shorts, Reels e TikToks (9:16 a 60 FPS).

## Arquitetura Normativa
Consulte o documento completo: [ARQUITETURA_ETAPA_1.md](file:///D:/cazador%20-%20videos%20curtos/ARQUITETURA_ETAPA_1.md)

## Como Operar
1. **Calibração:** Inspecione `config/iqoption_coords.json`.
2. **Gravação:** Execute `python scripts/screen_recorder.py`.
3. **Takes Homologados:** Consulte a pasta `raw_recordings/`.
