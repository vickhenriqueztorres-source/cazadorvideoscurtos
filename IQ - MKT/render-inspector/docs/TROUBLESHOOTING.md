# Troubleshooting

- **Login:** faça-o manualmente no perfil aberto e reinicie; o perfil persiste.
- **Porta 8765 ocupada:** encerre a instância anterior.
- **Chrome não encontrado:** defina `RENDER_INSPECTOR_CHROME_PATH` para o executável.
- **INCONCLUSIVE:** significa que o renderer ou a origem específica não possui evidência suficiente.
- **Perfil bloqueado:** encerre somente a instância anterior do Render Inspector.
